# 🤖 CLI Chatbot

A terminal-based AI chatbot built with **Python**, featuring conversational memory and support for different AI providers.

### ✨ Features

- 💬 Interactive CLI conversations
- 🧠 Conversation memory
- 🔌 Modular AI provider architecture
- ⚙️ Command-line interface
- 💾 JSON-based conversation storage

### 🛠️ Built With

- Python
- AI APIs
- JSON

### 📂 Structure

- `cli.py` — command-line interface
- `providers.py` — AI provider handling
- `memory.py` — conversation memory
- `conversation.json` — stored conversation data
